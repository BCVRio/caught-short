# Caught Short

Mobile WebAR toilet-finder game by BCVR Immersive. Live at https://loo.bcvr.io

- root (`index.html`, `aframe.min.js`, `assets/`) – Festive Edition on open WebXR / camera-feed mode, no Zappar. Notes in `README-open.md`.
- `festive/` – Festive Edition on Zappar Universal AR (the build behind https://webxr.run/eldN7R65O1Nz).
- `open/` – redirect to the root (kept for links already shared).

Deployed by GitHub Actions (`.github/workflows/pages.yml`) on every push to `main`.

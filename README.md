# Caught Short

Mobile WebAR toilet-finder game by BCVR Immersive.

- `open/` – Festive Edition rebuilt on open WebXR / camera-feed mode (no Zappar). See `open/README.md`.
- `festive/` – Festive Edition on Zappar Universal AR (the build behind https://webxr.run/eldN7R65O1Nz).

Served via GitHub Pages: https://bcvrio.github.io/caught-short/
